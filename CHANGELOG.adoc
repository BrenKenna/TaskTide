- [/] Slow queue for >30 elements

        - Still works, but becomes slow after this as 40 took 3mins. 15-25 is a good number.

        - Bucket leader claiming requires recursively leadership across buckets up to root queue.

        - Decision still sort of slow though, maybe reduce file deletion frequency & jitter.
