## TaskTide - Manager
Library uses TaskTide-Core library for broader use of TaskTideServices, including bulk operations around importing/dropping tasks, resetting tasks if incomplete, fetching logs for error state, monitoring deployment etc.

Library/client pulls together underlying class, and it's use to one module
